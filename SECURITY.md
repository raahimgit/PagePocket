# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on this repository (Security tab, Report a vulnerability). Include the browser and version, steps to reproduce, and the impact you expect.

This is a volunteer project; reports are handled on a best-effort basis.

## Scope

Of particular interest:

- Anything that makes the extension send data off the device.
- Script or markup injection from captured page content or from an imported file.
- Input handling that crashes, hangs or corrupts storage (oversized, malformed or hostile pages and imports).
- Permission use beyond what the README documents.

## Supported versions

Only the latest release is supported.
